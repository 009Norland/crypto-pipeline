How it works

Each run does the same five things, in this order.

  1. Ask CoinGecko. The pipeline requests the current price, market cap and 24-hour volume for each coin you follow.
  2. Check the answer. If a coin is missing or a price is zero or negative, the run stops before anything is saved.
  3. Keep an untouched copy. Everything goes into raw_prices as it arrived, so you can always go back to the source.
  4. Tidy it up. Coins go into dim_coin and prices into fact_price, so questions are easy to ask.
  5. Double-check. The raw and tidy tables should hold the same number of rows. If they don't, the run says so.
